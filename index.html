What do these scores & metrics mean?

Category Scores (0–100)

Perf — Performance
How fast the page loads and becomes usable. Combines FCP, LCP, TBT, CLS, and Speed Index into a weighted score. Most impactful for user experience.
A11y — Accessibility
Whether the page is usable by people with disabilities. Checks color contrast, labels, ARIA attributes, keyboard navigation, heading structure, and more.
BP — Best Practices
Modern web standards compliance. Checks HTTPS, deprecated APIs, third-party cookies, console errors, image aspect ratios, and secure JavaScript.
SEO — Search Engine Optimization
How well search engines can discover and index the page. Checks meta descriptions, crawlability, structured data, link text, and mobile friendliness.

Performance Metrics

FCP — First Contentful Paint
Time until the browser renders the first piece of content (text, image, etc.). Target: under 1.8s. Shows how quickly something appears on screen.
LCP — Largest Contentful Paint
Time until the largest visible element (hero image, heading block) finishes rendering. Target: under 2.5s. Core Web Vital — Google uses this for ranking.
TBT — Total Blocking Time
Total time the main thread was blocked by long JavaScript tasks (>50ms each) between FCP and TTI. Target: under 200ms. Directly affects how responsive the page feels.
CLS — Cumulative Layout Shift
Measures visual stability — how much content moves around while loading. Target: under 0.1. High CLS means elements jump around as images/fonts/ads load. Core Web Vital.
TTI — Time to Interactive
Time until the page is fully interactive (responds to clicks/taps without delay). Long TTIs mean users see the page but can’t interact with it.
